# TypeScript Utilities Showcase

A modern, interactive web application that demonstrates common TypeScript utility functions and their implementations. Built with Next.js and React.

![TypeScript Utilities](https://img.shields.io/badge/TypeScript-Utilities-blue)
![Next.js](https://img.shields.io/badge/Next.js-14-black)
![React](https://img.shields.io/badge/React-19-blue)

## 📋 Overview

This project showcases various TypeScript utility functions that are commonly used in frontend development. Each utility comes with:

- Interactive demos to see the function in action
- Well-documented implementations
- Real-world use cases

## 🧰 Featured Utilities

- **Debounce Function**: Delay function execution for API calls
- **Deep Clone**: Create deep copies of objects without using JSON methods
- **Throttle Function**: Limit the rate of function execution
- **Array Flattening**: Convert nested arrays into a flat structure
- **Event Emitter**: Implementation of the publisher-subscriber pattern
- **Memoization**: Cache results of expensive operations
- **Concurrent Promise Handling**: Run promises with concurrency limits
- **Data Format Conversion**: Transform data between different formats
- **String Utilities**: Common string manipulation functions

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- pnpm (recommended) or npm

### Installation

1. Clone the repository

   ```bash
   git clone https://github.com/singhpoo/TypescriptRefresher.git
   cd TypescriptRefresher
   ```

2. Install dependencies

   ```bash
   pnpm install
   # or
   npm install
   ```

3. Start the development server

   ```bash
   pnpm dev
   # or
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser
